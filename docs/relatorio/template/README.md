# Modelo original de relatório

[Guia do relatório](../README.md)

Arquivos extraídos do `Main.zip` fornecido para a documentação. Seus conteúdos foram preservados, sem preencher nomes, título, resultados ou referências.

| Arquivo | Uso |
|---|---|
| [`Main.tex`](Main.tex) | Fonte principal do modelo |
| [`Main.pdf`](Main.pdf) | PDF de exemplo recebido, ainda não preenchido |
| [`refs.bib`](refs.bib) | Referências bibliográficas de exemplo |
| [`Teaser.pdf`](Teaser.pdf) | Figura de exemplo usada pelo modelo |
| [`icml2024.sty`](icml2024.sty) e [`icml2024.bst`](icml2024.bst) | Estilo do documento e da bibliografia |
| [`algorithm.sty`](algorithm.sty), [`algorithmic.sty`](algorithmic.sty), [`fancyhdr.sty`](fancyhdr.sty) | Arquivos de estilo que acompanham o material recebido |

Foram omitidos os produtos temporários de compilação: `.aux`, `.bbl`, `.blg`, `.log`, `.out` e `.synctex.gz`. Eles podem ser regenerados e não representam conteúdo autoral adicional do relatório.

O cabeçalho da fonte e os campos de exemplo precisam ser revisados antes da entrega. Consulte o [guia de preparação e compilação](../README.md) e trabalhe sobre uma cópia. Os avisos e identificações dos arquivos de estilo foram mantidos como recebidos.
